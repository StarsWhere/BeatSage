External dependencies and build tools

BSIPA, Harmony, BeatSaberMarkupLanguage, SiraUtil, SongCore, BetterSongList,
CustomJSONData, Counters+ and Camera2 are external references supplied by the
user's compatible game installation. Their binaries and source are not included
in these mod packages. Their original licenses continue to apply. Unity and
Beat Saber assemblies and the system Segoe UI Symbol font are read from the
local installation and are not redistributed.

NuGet downloads build-only tools and reference assemblies under their own
package terms, including BepInEx.AssemblyPublicizer.MSBuild 0.4.2 and
Microsoft.NETFramework.ReferenceAssemblies.net472 1.0.3. These tools and
reference assemblies are not included in the runtime mod packages.
